# Axiom Browser 0.1.1

Минимальный браузер для Windows 10/11 x64 на Rust и Microsoft Edge WebView2.

## Запуск

Дважды нажмите `launch.cmd`. Готовая программа находится в `dist/AxiomBrowser.exe`. Если EXE отсутствует, запускатель вызывает `cargo run --release`. Для готового EXE нужен только Microsoft Edge WebView2 Runtime, Rust и Visual Studio пользователю не нужны.

Введите адрес и нажмите Enter или Go. Без схемы используется HTTPS; `localhost:порт` открывается через HTTP. Кнопки Back, Forward и Reload управляют текущей страницей. При запуске открывается example.com.

Нажмите New tab, чтобы открыть пустую вкладку; выберите вкладку в списке рядом с кнопками. Close tab закрывает выбранную вкладку. При закрытии последней вкладки браузер завершает работу. Вкладки сохраняют свои страницы и отдельную историю переходов; cookie и профиль общие.

Горячие клавиши: `Ctrl+T` — новая вкладка, `Ctrl+W` — закрыть, `Ctrl+L` — адресная строка, `Ctrl+Tab` / `Ctrl+Shift+Tab` — следующая / предыдущая вкладка.

Профиль с cookie хранится в `%LOCALAPPDATA%\AxiomBrowser\Profile`. Обязательных серверов Axiom и телеметрии нет. Страницы напрямую соединяются со своими серверами.

## Сборка

Нужны Rust stable x86_64-pc-windows-msvc, Visual Studio C++ Build Tools, Windows SDK и WebView2 Runtime.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check-environment.ps1
cargo test --locked
cargo build --release --locked
New-Item -ItemType Directory -Force dist
Copy-Item target/release/axiom-browser.exe dist/AxiomBrowser.exe
```

## Проверка сайтов

```powershell
cargo run --locked -- --smoke-test
```

Проверка загружает HTTPS-сайты, проверяет навигацию и пять одновременно открытых вкладок. Проверяются общая COM-среда WebView2, общий cookie, сохранность JavaScript-состояния при переключении, выбор и циклическое переключение вкладок, защита вводимого адреса от фоновых событий и закрытие вкладок. Код выхода 0 означает успешный сценарий, 1 — ошибку или таймаут 60 секунд. Используется отдельный профиль `.smoke-profile`.

## Объём версии

Одно окно с несколькими вкладками: адресная строка, HTTPS/HTTP, навигация, изменение размера окна и постоянный профиль. Скрытые вкладки продолжают работать, автоматического сна и выгрузки ещё нет. Запрашиваемые разрешения и дополнительные окна запрещены. Интерфейс разрешений, сохранение сессии, журнал истории, закладки, экономия памяти, дизайн и оптимизация будут отдельными этапами. Не проверена совместимость каждого сайта, DRM и сложных авторизаций.

Полный технический план находится в `docs/Axiom_Browser_Technical_Plan_v0.1.md`; эта версия реализует базовый браузер с вкладками. Следующий этап — локальная история, закладки и восстановление сессии.
