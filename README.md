# Axiom Browser 0.1.6

Небольшой браузер для Windows 10/11 x64 на Rust, Wry и Microsoft Edge WebView2. Интерфейс и внутренние страницы оформлены в палитре Void: глубокий графит, сдержанный фиолетовый оттенок и чёткие контуры. Сайты сохраняют собственное оформление.

## Запуск и навигация

Дважды нажмите `launch.cmd`. Готовая программа находится в `dist/AxiomBrowser.exe`; если её нет, запускатель вызывает `cargo run --release`. Для готового EXE нужен Microsoft Edge WebView2 Runtime.

Введите адрес или запрос и нажмите Enter. Можно выбрать Google, Bing или DuckDuckGo; домены открываются по HTTPS, localhost и loopback — по HTTP. Кнопки и сочетания `Alt+←` / `Alt+→` переходят назад и вперёд; `Ctrl+R` и `F5` обновляют страницу.

Адресная панель и вкладки используют нативные элементы Windows с тёмным оформлением, GDI-иконками сайтов и подсказками. Перетаскивайте вкладки для изменения порядка; при переполнении можно прокручивать полоску вкладок. Закреплённые вкладки занимают компактное место и остаются слева после перезапуска. Их можно закрыть средней кнопкой мыши, `Ctrl+W` или через контекстное меню. Команды «Закрыть другие вкладки» и «Закрыть вкладки справа» сохраняют закреплённые вкладки. Контекстное меню также позволяет закрепить вкладку, дублировать её или переместить влево/вправо.

`Ctrl+Shift+T` восстанавливает одну из последних 20 закрытых вкладок в текущем запуске, включая её состояние закрепления. Дублируется адрес текущей вкладки; значения форм и JavaScript-состояние не копируются.

## Настройки, история и закладки

Настройки позволяют выбрать стартовую страницу, домашний адрес, поисковую систему, восстановление прошлой сессии и ленивую либо полную загрузку восстановленных вкладок. Масштаб страниц регулируется от 50% до 200% и применяется сразу к уже открытым и новым страницам. Дополнительно можно включить подтверждение закрытия нескольких вкладок и отключить запись истории; историю можно очистить из её страницы. Сохранённые параметры переживают перезапуск.

![Настройки Axiom Browser](docs/axiom-0.1.5-settings.png)

`Ctrl+D` открывает нативное окно редактора закладки. Укажите название и адрес, затем нажмите «Сохранить»; открытие окна само по себе не сохраняет страницу. При редактировании доступны «Сохранить», «Отмена» и «Удалить» с подтверждением удаления. Менеджер закладок поддерживает поиск и открытие записей в текущей или новой вкладке. Повторное сохранение того же URL обновляет существующую запись. Команда «Открыть все» создаёт вкладки для сохранённых адресов.

![Нативный редактор закладок Axiom Browser 0.1.6](docs/axiom-0.1.6-bookmark-editor.png)

Меню «⋮» открывает историю (`Ctrl+H`), закладки (`Ctrl+Shift+O`) и настройки. Звезда рядом с адресом и `Ctrl+D` открывают редактор закладки; сохранение происходит только по кнопке «Сохранить». Восстановление сессии возвращает URL и заголовки, но не значения форм, JavaScript-состояние и историю переходов внутри вкладки. Одновременно разрешён один обычный экземпляр браузера; повторный запуск сообщает об уже открытом окне.

Горячие клавиши: `Ctrl+T` — новая вкладка, `Ctrl+W` — закрыть, `Ctrl+L` — адресная строка, `Ctrl+Tab` / `Ctrl+Shift+Tab` — следующая / предыдущая вкладка, `Ctrl+Shift+T` — восстановить закрытую вкладку.

Профиль с cookie находится в `%LOCALAPPDATA%\AxiomBrowser\Profile`; сессия, настройки, история и закладки хранятся в `browser.sqlite3` в этой папке. Обязательных серверов Axiom и телеметрии нет.

## Сборка и проверки

Для сборки нужны Rust stable `x86_64-pc-windows-msvc`, Visual Studio C++ Build Tools, Windows SDK и WebView2 Runtime.

```powershell
powershell -ExecutionPolicy Bypass -File scripts/check-environment.ps1
cargo test --locked
cargo build --release --locked
New-Item -ItemType Directory -Force dist
Copy-Item target/release/axiom-browser.exe dist/AxiomBrowser.exe
```

В 0.1.6 прошли 37 модульных тестов и release-сборка. Восстановление сессии прошло в ленивом и полном режимах; отдельно проверены favicon WebView2, перетаскивание вкладок, закрепление и восстановление порядка после перезапуска, а также сохранение и редактирование новых и существующих закладок в нативном окне. Итоговая smoke-проверка ещё выполняется. Команды и уточнения приведены в [`docs/verification-0.1.6.md`](docs/verification-0.1.6.md).

Для запуска отдельного smoke-сценария:

```powershell
cargo run --locked -- --smoke-test
```

Он использует изолированный профиль `.smoke-profile`. Результаты актуальной проверки будут отражены в протоколе 0.1.6 после завершения финального запуска.
