# Проверка версии 0.1.3 — путь 1

13 октября 2026, Windows x64, Rust/Cargo 1.99.0, WebView2 154.0.4258.62.

- 19 модульных тестов успешно: адреса/поиск, вкладки, раскладка, SQLite и безопасный вывод записей в HTML.
- Проверены повторное открытие БД, сессия/закладки/история, исправление активного индекса после фильтрации некорректного URL, сохранение предыдущей сессии при неудачной записи.
- Release-сборка без предупреждений успешна.
- Реальный сетевой smoke-тест прежней навигации, пяти вкладок и поиска прошёл с кодом 0.
- Два отдельных запуска `--seed-session-test` и `--restore-test` прошли с кодом 0. Восстановлены три вкладки с выбранной второй; создан один WebView. После выбора первой число WebView стало два, третья не загрузилась. Проверены запись истории, закладка Rust и отображение страницы истории.
- Клиентская область окна после добавления звёздочки и меню визуально проверена через PrintWindow.

Тесты используют отдельные профили. Подтверждено восстановление URL/заголовков и выбранной вкладки; состояние JavaScript, значения форм, прокрутка и навигационная история отдельной вкладки между запусками не сохраняются. Прерывание процесса во время физической записи, повреждение файла БД и физические клики по меню отдельно не моделировались. SQLite-транзакции обеспечивают целостность обычных обновлений сессии.

Следующий этап начинается после пользовательского тестирования этой версии.
