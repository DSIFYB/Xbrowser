# Axiom — Void

Выбранный подход: глубокий графит, небольшая холодная фиолетовая примесь и много спокойного свободного пространства. Ощущение глубины создают слои интерфейса и тонкие границы. Космос передаётся цветом и воздухом. Никаких звёзд, туманностей, шумовых текстур, свечения и фонового движения.

Это проектное решение для Axiom, а не готовая тема Fluent. Макет рядом: `void-preview.html`. Он демонстрирует оформление; элементы макета не являются действующим браузером.

## Цвета

| Токен | HEX | Назначение |
|---|---|---|
| base | `#0D0F14` | Страница новой вкладки, фон внутренних страниц |
| strip | `#11141B` | Полоса вкладок |
| surface | `#181C25` | Toolbar, карточки настроек, списки закладок |
| raised | `#232938` | Активная вкладка, адресное поле, выбранный раздел |
| hover | `#2C3446` | Hover кнопок и строк |
| border | `#384156` | Тонкие декоративные границы и разделители |
| text | `#EDF0F7` | Заголовки, текст адреса и полей |
| secondary | `#AAB4C8` | Описания, URL, неактивные иконки и вкладки |
| accent | `#B6ADFF` | Focus, активные иконки, ссылки, основная кнопка |
| accent-soft | `#302E47` | Фон выбранного пункта внутренней навигации |
| accent-ink | `#171326` | Текст на заполненной accent-кнопке |
| danger | `#FF9CAA` | Удаление, ошибки, hover закрытия |
| success | `#9FDCC0` | Сообщение о сохранённых настройках |

Проверено вычислением относительной яркости sRGB: text/surface **14.95:1**, secondary/raised **6.97:1**, accent/raised **7.20:1**, accent-ink/accent **8.99:1**. `border` не предназначен для текста; клавиатурный focus — сплошной accent-контур 2 px. Цвет не должен быть единственным указанием выбранного или опасного состояния.

Нейтральные слои и редкий акцент соответствуют рекомендациям [Fluent Color](https://fluent2.microsoft.design/color). Семантические danger/success используются только для обратной связи. [Fluent Typography](https://fluent2.microsoft.design/typography) задаёт ориентир контраста обычного текста 4.5:1.

## Шрифт и размеры

- Native GDI: **Segoe UI**. Проверено наличие `C:\Windows\Fonts\segoeui.ttf` на текущем компьютере. Ничего скачивать не требуется.
- HTML: `"Segoe UI Variable", "Segoe UI", system-ui, sans-serif`. Первый шрифт используется только если установлен; стабильный fallback — Segoe UI. Не поставлять системные шрифты в архиве приложения.
- Обычный текст и адрес: 15 px / 22 px, weight 400. Подписи и вкладки: 14 px / 20 px. URL/метаданные: 13 px / 18 px. Не уменьшать подписи ради дополнительной плотности.
- Заголовок внутренних страниц: 30 px / 38 px, weight 600. Заголовки групп: 18 px / 26 px, weight 600. Заголовок новой вкладки: 40 px / 48 px, weight 600.
- GDI: effective px × DPI scale, `CLEARTYPE_QUALITY`; regular400, active600. Не делать весь интерфейс semibold.

Segoe UI и единая типографическая иерархия выбраны по [Microsoft Typography in Windows](https://learn.microsoft.com/windows/apps/design/signature-experiences/typography). Для русских названий оставлять нормальный регистр и многоточие при переполнении.

## Геометрия и ритм

- Базовый шаг: 4 px. Рабочие интервалы: 8, 12, 16, 24, 32 px.
- Сохранить общую высоту browser chrome около 100 effective px: вкладки44 + toolbar56. Обновление не должно забирать ещё больше места у сайтов.
- Вкладка: высота36, верхний отступ6, радиус12, ширина160–232. Активная — raised; неактивная — strip, hover — surface. Название + небольшой сайт-маркер + отдельный крестик. Не использовать декоративную точку как единственное обозначение сайта.
- Кнопки toolbar: цель36×36, иконка18–20, радиус8. Крестик вкладки: цель24×24. Не путать размер рисунка с размером кликабельной области.
- Адрес: высота36, радиус12, фонraised, обычная границаborder1px, focusaccent2px. Контур обязателен при клавиатурном фокусе.
- Карточки: радиус16; внутренние поля16–24. Формы: радиус10–12, высота40. Тени только на popup при необходимости; слои достаточно различаются цветом.
- Внутренние страницы: ширина контента920px, поля24px; формы и длинные списки — до760px. На узких окнах колонки переходят в одну.

## Иконки

Выбрана одна простая контурная семья, по характеру близкая к Lucide и Fluent Regular. Реализация — собственные геометрические примитивы GDI, одинаковый штрих 1.7–2 effective px, без новых пакетов и без зависимостей от иконочного шрифта. Для HTML те же формы можно рисовать небольшими inline SVG с `currentColor`.

| Действие | Форма |
|---|---|
| Назад / вперёд | Горизонтальная линия и две диагонали стрелки |
| Обновить | Разомкнутая круговая дуга и короткий наконечник |
| Поиск | Круг с диагональной ручкой |
| Новая вкладка | Две пересекающиеся линии одинаковой длины |
| Закрыть | Две диагонали; danger только на hover |
| Закладка | Знакомая пятиконечная звезда: контур пустая, solid accent сохранённая |
| Закрепить | Контур pin, отдельный от favicon индикатор |
| Меню | Три равноразмерных точки |
| Настройки | Компактная шестерёнка; рядом текст в меню/странице |
| История | Круг часов с двумя стрелками |
| Удалить | Прямоугольная корзина с крышкой |

Звезда здесь — только привычная кнопка сохранения страницы, не фоновый декор. Не рисовать emoji или смешивать текстовые Unicode☆/★, SVG и разные случайные толщины. Для кнопок добавить понятное имя и tooltip; если action не очевиден, показывать подпись.

Подход опирается на [Fluent Iconography](https://fluent2.microsoft.design/iconography): regular для действий, filled для выбранного состояния, одноцветность и узнаваемая семантика. [Lucide](https://lucide.dev/) — визуальный ориентир согласованных контуров, не новая runtime-зависимость. [Microsoft Segoe Fluent Icons](https://learn.microsoft.com/en-us/windows/apps/design/iconography/segoe-fluent-icons-font) предупреждает, что шрифт не предустановлен на Windows10; поэтому GDI-примитивы надёжнее.

## Состояния и поведение

**Вкладки.** Активная отличается слоем raised, semibold-текстом и короткой accent-линией снизу. Наведение отдельной кнопки закрытия не закрашивает всю вкладку danger. Закреплённая вкладка имеет pin-индикатор и сокращённый размер. Переполнение раскрывает явные стрелки и список всех вкладок; счётчик полезнее нечитаемых вкладок шириной40. Состояния загрузки/ошибки сообщать формой или подписью, не только цветом. Контекстное меню: новая, дублировать, закрепить/открепить, закрыть, закрыть другие; восстановить закрытую — общий пункт и Ctrl+Shift+T.

**Toolbar.** Назад/вперёд disabled не имеют hover, но остаются видимыми. Адресное поле — главный горизонтальный объект; поиск и URL используют одну позицию. Сохранённая закладка заполнена accent; повторное нажатие открывает редактор. При фокусе адреса текст выделяется, рамкаaccent показывает режим ввода. Статус защищённости добавлять только при реальной проверке данных; декоративный замок может создавать неверное обещание.

**Новая вкладка.** Однотонный base, небольшая рамочная монограмма A, заголовок Axiom, одно поисковое поле и 3–6 коротких ссылок. Основное содержимое располагается ближе к верхней трети. Можно тонкое outline-кольцо вокруг монограммы, без сияния. Основной поиск — ширина600–680px, высота52; никаких тяжёлых картинок.

**Закладки/история.** Единый header с переходами в историю, закладки, настройки. Сначала название и поиск, потом список. Заголовок сохранённой страницы —text; полныйURL —secondary; действия редактирования/удаления не перетягивают внимание. Поиск и открыть все остаются видимыми. Редактор — отдельная карточка сверху со значениями и явными Сохранить/Отмена. На узком окне действия строки переносятся под названием. Не полагаться на favicon от удалённого сайта для локальной страницы.

**Настройки.** Короткое введение и группы «Запуск и вкладки», «Поиск и новая вкладка», «Внешний вид». У каждой строки слева название+объяснение, справа контрол; при узкой ширине контрол ниже. Сохранение — одна понятная primary-кнопка в конце формы. Уведомление сохранения в role=status, цветsuccess, текст сохраняется. Разделять настройки, которые применяются сразу, и после перезапуска короткой подписью. Связанные значения вроде фоновой загрузки должны иметь человеческое пояснение стоимости по памяти.

## Внедрение и проверка

1. Один источник токенов для GDI и HTML, чтобы вкладки и страницы выглядели как одно приложение.
2. Сначала dark Void на chrome и внутренних страницах; содержимое сайтов сохраняет авторские цвета. Выбор светлой/тёмной темы — отдельная настройка, не принудительная перекраска сайтов.
3. Проверить actual app при100%,125%,150%DPI: адресные поля, native EDIT фон, checkbox/select, обрезание длинных русских вкладок, hover, focus, восстановленные вкладки.
4. Проверить клавиатуру и тёмные формы: светлый caret/selection, работаTab, disabled-кнопки, сохранённая закладка.
5. Проверить длинныйURL, пустойсписок, 20вкладок, узкоеокно; новое оформление не должно повторить ошибку скрытых вкладок после восстановления.
