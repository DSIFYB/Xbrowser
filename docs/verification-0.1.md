# Проверка версии 0.1.0

Дата: 13 октября 2026. Windows x64, Rust/Cargo 1.99.0, WebView2 154.0.4258.62.

- Проверка окружения: Rust, Cargo, MSVC, Windows SDK, WebView2.
- `cargo test --offline --locked`: 4 теста успешны.
- `cargo build --release --offline --locked`: успешно, EXE 1 199 616 байт.
- Release EXE `--smoke-test`: код 0, пять загрузок с проверкой DOM.
- example.com → ввод rust-lang.org через обработчик адресной строки → назад → вперёд → обновление.
- Изменение размера окна до 900 × 600 выполнено между переходами.

Тест подтверждает загрузку содержимого HTTPS и работу обработчиков навигации. Он не имитирует физические клики и клавиатуру, не измеряет производительность и не подтверждает совместимость всех сайтов. Постоянство cookie между запусками отдельно не тестировалось. Браузер использует штатный профиль WebView2.

Первый запуск smoke-теста в песочнице завершился таймаутом: для WebView2 потребовался обычный доступ к окружению Windows. Проверенная release-сборка запускалась вне песочницы.
