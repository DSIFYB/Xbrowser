# Проверка версии 0.1.1

Дата: 13 октября 2026. Windows x64, Rust/Cargo 1.99.0, WebView2 154.0.4258.62.

- `cargo test --offline --locked`: 8 тестов успешны. Покрыты адреса, выбор и закрытие вкладок, соседняя вкладка, последний элемент и устаревшие ID.
- `cargo build --release --offline --locked`: успешно.
- Release EXE `--smoke-test`: код 0, девять реальных загрузок HTTPS и десять проверок содержимого/состояния.
- Сохранена навигация предыдущей версии: адресная строка, назад, вперёд, обновление и изменение размера окна.
- Открыты одновременно пять вкладок; COM-среда одинакова, cookie, установленный в первой вкладке, доступен во второй.
- `IsVisible` подтверждает видимость только активной вкладки. JavaScript-маркер сохраняется при возвращении к скрытой вкладке.
- Проверены нативный selector и циклическое переключение в обоих направлениях.
- Фоновые события не заменяют неотправленный адрес. События закрытой вкладки игнорируются.
- Проверены создание новой пустой вкладки, закрытие фоновой, активной и последней вкладок.
- Горячие клавиши подключены к native message queue и WebView2 AcceleratorKeyPressed для фокуса внутри страницы. Регистрация обработчиков успешна при создании всех тестовых вкладок.

Smoke-тест использует реальные WebView2 и сеть, но вызывает обработчики приложения и Win32-контролы программно. Физические клики и сочетания клавиш отдельно не проверены. Сохранность cookie между перезапусками, долгие сессии и расход памяти отдельно не измерялись. При закрытии вкладки её JavaScript-состояние уничтожается; восстановление закрытых вкладок пока отсутствует.
