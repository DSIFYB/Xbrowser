# Проверка Axiom Browser 0.1.5

В этой версии оформлены нативная панель и внутренние страницы в палитре Void. Снимки главной страницы, настроек и менеджера закладок сделаны в работающем приложении и проверены после исправления отрисовки кнопки «Назад».

## Результаты

- Прошли 35 модульных тестов.
- Проверено восстановление с ленивой и полной загрузкой: оба запуска завершились `CORE_VERIFIED`, восстановлены четыре видимые вкладки.
- В реальном приложении проверены добавление закладки, дедупликация повторного URL, редактирование, открытие всех закладок и удаление после подтверждения.
- Проверены сохранение настроек масштаба 125%, очистка истории и отключение записи истории.
- Проверены дублирование вкладки, перемещение, закрытие и восстановление закрытой вкладки.
- 12-шаговая smoke-проверка завершилась `TABS_VERIFIED` с пятью вкладками. Подтверждены общая среда WebView2, общие cookie, сохранение JavaScript-состояния и адресного ввода, создание новой вкладки с Google-поиском, закрытие вкладок и защита от устаревших событий.

## Воспроизведение восстановления

Посев и проверка запускаются отдельно. Они используют профиль `.restore-profile`, не основной профиль.

```powershell
cargo run --locked -- --seed-session-test
cargo run --locked -- --restore-test
```

Чтобы восстановленные страницы загружались все сразу:

```powershell
cargo run --locked -- --seed-session-test --restore-all
cargo run --locked -- --restore-test
```

Smoke-сценарий запускается отдельно и использует профиль `.smoke-profile`:

```powershell
cargo run --locked -- --smoke-test
```

Результат финального запуска: `PASS`, 12 шагов, `TABS_VERIFIED`, пять вкладок.
